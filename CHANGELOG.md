# Changelog

## v0.1.0 — first public release

- Composer-installable Yii2 ActiveRecord time-series Chart.js widget.
- Count, sum, average, minimum and maximum aggregations.
- Hourly, daily and monthly buckets across selected calendar periods.
- MySQL/MariaDB and PostgreSQL query support.
- Chart types: bar, line, pie and doughnut.
- Public PHP namespace: `Ktulchu\\Yii2Chart` (replaces the pre-release `rkdev\\chart`).
- PHP 8.0+, Yii2 2.0.50+; smoke checks and database integration CI.

Install from Packagist:

```bash
composer require ktulchu/yii2-chart:^0.1
```

Before v0.1.0, the GitHub repository did not publish a stable tagged release.
